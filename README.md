# Niraja's creaction

A sleek, modern, and responsive web-based standard calculator created by Niraja, built with vanilla HTML5, CSS3, and JavaScript.

## Features

- **Speech & Audio Narration**:
  - Automatically speaks numbers as you press them (e.g. "4", "5", "point").
  - Announces symbols and operators (e.g. "plus", "minus", "times", "divided by").
  - When `=` is pressed, plays an audio chime and speaks the full equation and result aloud (e.g. *"4 plus 5 equals 9"*).
  - Can be muted or unmuted anytime using the sound button (`🔊` / `🔇`).
- **Single-Line Equation Display**: Complete calculation displays in one continuous line (e.g. `4 + 5 = 9`).
- **Standard Arithmetic Operations**: Addition (`+`), Subtraction (`−`), Multiplication (`×`), Division (`÷`), Percentage (`%`), Sign Negation (`±`).
- **Precision Calculation**: Floating-point rounding eliminates JavaScript floating point inaccuracies (e.g. `0.1 + 0.2 = 0.3`).
- **Full Physical Keyboard Support**:
  - Digits `0`–`9` and decimal `.` or `,`
  - Operators `+`, `-`, `*` or `x`, `/`, `%`
  - Calculate with `Enter` or `=`
  - Clear with `Escape` or `c`
  - Delete with `Backspace`
  - Negate with `n`
- **Calculation History**:
  - Slide-out drawer tracking past expressions and answers.
  - Click any previous calculation to reuse its value.
  - Persisted in local storage.
- **Theme Switcher**:
  - Dark mode (Obsidian / Indigo glass)
  - Light mode (Crisp soft-gray & slate)
- **Audio Feedback**: Subtle, pleasant Web Audio API tactile clicks (toggleable on/off).
- **Click to Copy**: Click on the display screen to copy the active number to your clipboard.
- **Responsive Layout**: Designed for seamless use on desktop, tablet, and mobile browsers.
